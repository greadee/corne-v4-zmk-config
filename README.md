## GPIO Pins 
- Diode direction is set to row -> col
- GPIO row pins `0.22`, `0.24`, `1.00`, `1.11`, `1.04` and `0.29` correspond to physical columns 1 through 6.
- Physical columns 1 through 6 throw keys at locations $(0,y), (1,y), (2,y), (3,y), (7,y), (4,y)$ respectively.
- GPIO col pins `1.11`, `1.12`, `1.15` and `1.02` throw keys at locations $(x,0), (x,1), (x,2), (x,3)$, which is reversed for the left side.
